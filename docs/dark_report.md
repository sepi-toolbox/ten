# 어둠 개편 — 설계 보고

성권이 준 목록 그대로 옮기고, **공/체만 예산 공식으로 채웠다.** 아직 게임에는 안 올렸다 —
이 표를 승인받고 나서 1단계를 배포한다.

카드 **49종**(크리처 26 + 토큰 3 · 스펠 15 + 토큰 4 · 인챈트 4)에 지형 6종.
시작 덱은 **20종 23장**(전부 커먼), 커브 1코 4 · 2코 7 · 3코 7 · 4코 5 로 불·물과 같은 꼴이다.
나머지는 카드 풀에만 두고 원정 보상·상점으로 얻는다.

## 읽는 법

- **소모/예산** — 왼쪽이 그 카드가 쓴 값, 오른쪽이 코스트·희귀도가 허락한 값.
  `2A+H`(일반) · `2A+2H`(수호) · `4A+H`(비행) 로 잰다.
- **판정** — `적정` = 딱 맞음 · `여유 −N` = 더 강하게 만들 수 있음 · `초과 +N` = 넘음.
- **토큰** — 다른 카드가 만들어 내기만 하는 몸. 값은 부모 카드가 이미 냈으므로 검산에서 뺀다
  (미이라가 출진에서 −12 를 치르고 관 3장을 넣는 식).

## 지형

| 이름 | 종류 | 규칙 |
|---|---|---|
| 죽음의 늪 · 죽음의 호수 · 죽음의 대지 | 기본 | 어둠 자원 1 생성 · 즉시 사용 |
| 망각의 숲 | 평범 + 추가 | 어둠 자원 1 생성 · **지형을 이미 놓았어도 추가로 놓는다** |
| 묘지 | 특수(레어) | 자원을 만들지 않는다 · 내 크리처가 소멸할 때마다 좀비랫 소환 |
| 저주의 땅 | 추가 + 특수(레어) | **자원 2를 내고 놓는다** · 자원을 만들지 않는다 · 내 턴 종료마다 카드 1장 |

기본 지형 셋은 불·물과 같은 방식으로 원정 덱 17장에 **6/6/5 로 고르게** 섞인다.

## 내가 정한 것 — 틀리면 말씀해 주세요

1. **'출진'** — 소환할 때 발동하는 능력의 이름. 기존 '개전'(덱에 있으면 게임 시작 시 스스로
   발동)과 규칙이 달라 새 이름으로 뒀다. **'단말마'** 는 소멸할 때 발동.
   둘 다 키워드표에 고정값을 못 넣는다(붙는 효과가 카드마다 다르다) — 값은 카드마다 매기고
   문구 앞머리에만 이름을 단다. 엔진은 인쇄된 '출진 —' / '단말마 —' 를 읽는다.
2. **좀비렛 = 좀비랫.** 1코 크리처와 묘지 지형이 뽑는 토큰을 같은 카드로 보고 **'좀비랫'** 으로
   통일했다. 다른 카드라면 말씀해 주세요.
3. **부활은 죽은 자리에.** 스켈톤·스컬 기마병·본맘모스는 1회, 본드래곤은 공체가 남는 동안 반복.
   값은 **제 예산의 38%** 로 잡았다(증식 ×0.55 보다 싼 이유는 순차라서 — 한 몸씩만 서 있다).
4. **제물 수치** — 목록에 '제물' 이라고만 쓰인 카드는 코스트에 맞춰 4/6/8 로 정했다.
   데스핸드·크릴크로우 4 · 레이스·서큐버스 6 · 뱀파이어 8 · 동냥 8.
5. **미지정 토큰 스탯** — 관 0/3 수호 · 미이라 군주 10/12 · 늑대인간 4/4.
   해그의 시약(내 HP 3 회복) · 극독(크리처 3 피해) · 버섯(+2/+0) 은 전부 0코.
6. **다크조커의 '적'** — 상대 크리처와 상대 본체 둘 다로 잡았다.
7. **저주의 땅의 드로우는 매 턴**(내 턴 종료마다 1장). 바닷속 풍경과 같은 꼴이다.
8. **망각의 숲** — "2개 낼 수 있는" 을 '턴당 1장 제한을 안 먹는 평범한 지형' 으로 옮겼다.
   그래서 손에 두 장이 있으면 한 턴에 세 장(보통 1 + 망각 2)까지 깔린다.
   **한 턴에 딱 한 장만 추가** 로 막아야 하면 말씀해 주세요.

## 확인이 필요한 것 5가지

1. **듀라한의 머리** — "그 카드를 뽑으면 머리를 다시 덱에 넣고 공체 4 증가" 에서, 늘어나는 것이
   **판 위의 듀라한**입니까? 그렇다면 듀라한이 이미 죽었을 때는 어떻게 됩니까
   (아무 일도 안 일어남 / 그래도 머리는 덱으로 돌아감 / 손의 듀라한 카드가 커짐)?
2. **네크로맨서** — '출진(소환 시)' 으로 읽었습니다. 단말마여야 하면 알려 주세요.
   그리고 '모두 복제' 의 대상이 **내 판의 단말마 크리처**가 맞습니까(상대 것도 포함?)?
3. **서큐버스·쉐도우의 탈취** — 가져온 크리처는 **판이 끝날 때까지 내 것**입니까,
   아니면 이번 턴만입니까? 그리고 되돌려받는 장치는 없는 걸로 갑니까?
4. **포그위저드** — '모든 아군 면역' 은 포그위저드가 살아 있는 동안만이고,
   죽으면 부여했던 면역이 **전부 풀린다**는 뜻이 맞습니까?
   (면역은 수호와 양립하지 않아, 내 수호 크리처가 면역을 얻으면 수호가 풀립니다 — 괜찮습니까?)
5. **몸통던지기의 '모든 적'** — 상대 크리처 전체입니까, 상대 크리처 + 본체입니까?
