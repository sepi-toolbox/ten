# TEN

슬롯 10개의 카드 배틀러. 크리처끼리는 전투하지 않고, 각자 **자기 턴 종료마다 상대 플레이어를 때린다.** 개입 수단은 오직 **스펠**과 **수호**뿐이다. 그래서 모든 판단이 "얼마나 빨리 쌓느냐"와 "언제 끊느냐" 두 축으로 수렴한다.

| 상수 | 값 |
|---|---|
| 시작 HP | 60 |
| 마나 상한 | 6 (매 턴 1씩 충전) |
| 보드 슬롯 | 10 (크리처·인챈트 공유) |
| 스택 상한 | 5 (동명 크리처 중첩) |
| 덱 사이즈 | 30 |
| 예상 턴 수 | 10–13 |

## 핵심 규칙

- **크리처** — ATK/HP를 가지며 내 턴 종료 시 ATK만큼 상대를 때린다. 초과 피해는 이월되지 않는다(수호는 "피해량"이 아니라 공격 횟수를 흡수).
- **스펠** — 즉시 소모. 크리처 HP나 인챈트 충전을 같은 눈금으로 깎는다. 상대 보드에 개입하는 유일한 수단.
- **인챈트** — 충전량을 갖고 필드에 남으며 소진되면 사라진다. 슬롯을 크리처와 공유하므로 기회비용이 붙는다.
- **수호** — 플레이어 대신 왼쪽 슬롯부터 자동으로 피해를 받는다. 직접 피해 스펠은 관통.
- **비행** — 비행 없는 수호를 무시한다.

## 워크플로

밸런스 시트가 유일한 원본이다. 카드 수치는 `data/ten_balance.xlsx`에서만 수정한다.

```bash
pip install openpyxl
python3 tools/extract_cards.py     # xlsx → CSV/JSON 재생성
python3 tools/validate_budget.py   # 예산 초과·덱 사이즈 검산
```

`validate_budget.py`는 예산 초과 카드나 덱 사이즈 불일치가 있으면 종료 코드 1을 반환하므로 CI에서 밸런스 게이트로 쓸 수 있다.

## 예산 공식

```
크리처 예산   P(n) = round(a·n + b + (n−1)²·k) + 태그 보정      (a=3, b=1, k=0.5)
스탯 소모      일반 2A+H · 수호 2A+2H · 비행 4A+H
인챈트 총산출  T = 효과값 E × 충전 C
```

## 확정 규칙

- **덱 소진 = 즉시 패배** (누적 피해 없음). 덱이 빈 상태에서 드로우해야 하면 그 플레이어가 진다.
- **슬롯 만석 = 소환 불가** (밀어내기 없음). 10칸이 다 차면 새 크리처·인챈트를 낼 수 없다.

## 미확정 사항

- 인챈트 발동과 크리처 공격의 선후 관계 — 현재 **크리처 공격 → 인챈트(마지막)** 순으로 잠정 유지
- 비행+수호 조합의 예산 가중치 — 잠정치 사용 중
- 수호 파괴 보상 카드의 강도와 채용 수
